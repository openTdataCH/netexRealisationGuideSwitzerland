AccessibilityAssessment

→ Glossary definition

Purpose

An assessment of the usability by passengers with specific needs, for example, those needing wheelchair access, step-free access or for the visually or the auditorily impaired.

Table

Table: AccessibilityAssessment

Sub Element Usage Card Type Description Note
  MobilityImpairedAccess mandatory 1..1 LimitationStatusEnumeration Summary indication as to whether the component is considered to be accessible or not. Accessibility. Overall assessment for mobility and sensory impaired users. Allowed values: true, false, partial, unknown. partial means that AccessibiltyAssessments have to exist at lower levels like Quays or other elements. Some Quays may not be accessible if partial is used on the StopPlace.

++ StepFreeAccess expected 0..1 LimitationStatusEnumeration Whether a PLACE has step free access. Accessibility. If absent the value unknown is assumed. Allowed values: true, false, partial, unknown.

Usage Notes

In case of StopPlace or Quay, EPIAP uses the following interpretation: MobilityImpairedAccess set to true means:

  • WheelchairAccess true
  • StepFreeAccess true
  • VisualSignsAvailable true (only for railway stations)
  • TactileGuidanceAvailable true

Interpretation of AccessibilityLimitation:

We apply a slightly stricter interpretation than the current version of EPIAP. The information that can be conveyed to the passengers thus becomes more useful and exporting the data to foreign systems is unproblematic. The additional constraints are [marked in brackets].

   
WheelchairAccess 1.    StepFreeAccess [including EscalatorFreeAccess] from an accessible entrance (see next row).
2.    The stop / platform is sufficiently wide to make a turn with a wheelchair when entering / leaving the vehicles that usually stop at this stop / platform (depending on the available / needed tools for entering / leaving the vehicle).
3.    If boarding trains requires boarding assistance, onsite assistance is available.
StepFreeAccess 1.    A step-free route is an obstacle-free / barrier free [and EscalatorFreeAccess] route that meets the needs of mobility impaired persons. Changes in level are avoided or, when they cannot be avoided, they are bridged via ramps or lifts (compliant with PRM TSI).
2.    The platform or stop is accessible without steps from the surrounding area (footpaths).

A platform which has StepFreeAccess without WheelchairAccess (==false) may be not sufficiently wide to make a turn with a wheelchair.
StairFreeAccess A stair-free route. Single steps allowed, escalators allowed.
LevelAccessIntoVehicle Whether the platform is high enough and gap is small enough for level access into vehicle.

At least at a designated wheelchair door position the gap between platform and vehicle floor (of level access vehicle) does not exceed 75 mm measured horizontally and 50 mm measured vertically including sliding step (according to PRM TSI).
EscalatorFreeAccess (not included in profile) Reachable without using an escalator.
LiftFreeAccess (not included in profile) Reachable without using an elevator.
RampFreeAccess 1.   Reachable without using a ramp that doesn’t fit the UN Design Considerations (for instance, because they are too steep or a landing is missing in case of a ramp of more than 10 m).
2.    [The route provides WheelchairAccess].
AudibleSignalsAvailable Whether audible signals for the visually impaired are present.
VisualSignsAvailable 1.   PRM TSI: visual information as signposting, pictograms and dynamic information.
2.    [Largely language independent, also suited for passengers from foreign cultures.]
TactileGuidanceAvailable Whether the object has tactile guidance (for the visually impaired).
PRM TSI: obstacle-free route to each Quay for the visually impaired passengers equipped with tactile information.
For bus- and tram stops:
1.  Groundsurfaceindicator (at location first door) and/or full-length guideline (for boarding at all entrances)
2.   Tactile guideline or boarding position connected to a (natural) guideline in the environment

Remarks RampFreeAccess

  • Note that RampFreeAccess may very well include ramps - provided their slopes are only moderate or they have landing / rest areas.
  • RampFreeAccessis a stronger form of WheelchairAccess excluding steeper slopes.

Limitations of AccessibilityAssessment

  • If, e.g., WheelchairAccess or StairFreeAccess requires using a lift, the AccessibilityAssessment does not convey this information.
  • According to EPIAP definitions, a quay with, e.g., WheelchairAccess means that there is at least one entrance from which it is reachable. It may be that WheelchairAccess only works from a secondary entrance, not from the main entrance.

Such information can be encoded using SitePathLinks and PathJunctions that describe a routing network including accessibility and location data.

Entrances related to AccessibilityAssessment

  • All AccessibiltyLimitations (StepFreeAccess etc.) relate to a complete path from an “accessible” StopPlaceEntrance with DroppedKerb=true and DropOffPointClose=true.

StopPlaceEntrance

→ Glossary definition

Purpose

StopPlaceEntrances, in particular if DroppedKerbOutside and DropOffPointClose are true, are the reference points from which the accessibility of Quays and other place elements is assessed.

Table

Table: StopPlaceEntrance

Sub Element Usage Card Type Description Note
  Name mandatory 0..1 MultilingualString Name of STOP PLACE. Will be exported from ATLAS for ERA TSI PRM (Referenzpunkt - “Bezeichnung”).
  AccessibilityAssessment mandatory 0..1 AccessibilityAssessment_VersionedChildStructure Accessibility values associated with LEVEL. Accessibility. See the element’s table for all details.
  LevelRef expected 0..1 LevelRefStructure   Required if more than 1 level present.
  DroppedKerbOutside optional 0..1 boolean Whether nearest crossing to ENTRANCE has dropped kerb. Will be exported from ATLAS for ERA TSI PRM (only set to true if Verbindung from Parkplatz with “Stufenfreier Zugang” = Ja). To indicate starting point relevant for AccessibilityAssessments of Quays etc.
  DropOffPointClose optional 0..1 boolean Whether there is a drop off point close by to ENTRANCE. Will be exported from ATLAS for ERA TSI PRM (only set to true if Verbindung from Parkplatz with “Stufenfreier Zugang” = Ja). To indicate starting point relevant for AccessibilityAssessments of Quays etc.

Usage Notes

Modelling Rules for Navigation Networks

Which conventions and rules do we want to follow when modelling navigation networks? Which level(s) of details should we aim at? The following is intended as a starting point for a discussion.

Three possible ways to model a navigation network from a VehicleMeetingPoint (error: the idea was a drop off point or parking) to two Quays.

The first model includes localised vertices (e.g., Entrance, EquipmentPlace) connected by SitePathLinks and AccessEquipments (StairEquipment, RampEquipment).

VMP = VehicleMeetingPoint, E = Entrance, AS = AccessSpace, EP = EquipmentPlace, Q = Quay, arrow = SitePathLink

The second model uses localised and possibly non-localised (PathJunction) vertices, connected by similar SitePathLinks as the first model, but without Equipments and EquipmentPlaces.

PJ = PathJunction

The third model is a streamlined form that doesn’t insist on PathJunctions if they don’t provide additional information needed for accessibility routing.
